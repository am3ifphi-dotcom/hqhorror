# 自作アセット一覧とその理由 / Self-made assets

「外部で同等品質かつライセンスが確認できるものが**取得できなかった**ため自作した」ものと、
「演出上の都合で**最初から自作するほうが良い**」ものを分けて記載します。

---

## A. 外部が取得できず、やむなく自作したもの（代替品）

### A-1. 立ち絵（主人公・結衣） — `public/assets/portrait/*.png`

| 項目 | 内容 |
|---|---|
| 内容 | `yui_base` / `yui_blink` / `yui_fear` / `yui_look` の 4 種（274×1100 / 274×1100 / 283×1100 / 251×1100 px、背景透過）＋生成元の `*_raw.png` |
| 用途 | ダイアログ表示中の立ち絵。瞬き・呼吸（上下微動）・恐怖時の振動を CSS/JS で付与 |
| 理由 | 「立ち絵あるならそれをね」という要望に対し、OpenGameArt.org / itch.io が**ネットワーク制限で接続できず**、ライセンスが検証できる立ち絵を外部から取得できなかったため |
| 作り方 | 画像生成モデル（エージェントの `generate_image` ツール）で生成 → `tools/build_portrait.py` で背景除去（しきい値 10 / ぼかし 7 / ランプ 14 のアルファ生成＋最大連結成分抽出）・切り抜き・縦位置正規化 |
| 品質についての正直な注記 | ピクセルアートのゲーム本体（LPC 32–64px）に対して**立ち絵だけ描き起こしのイラスト**であるため、**トーンは完全には一致していません**。実行時に彩度を落とし、暗い色被りとノイズ（WebGL ポストエフェクト）を通すことで画面内では馴染ませています。より良い外部立ち絵が入手できた場合は `public/assets/portrait/` の 4 ファイルを差し替えるだけで反映されます（ファイル名・寸法の要件は `src/ui/ui.js` の `PORTRAITS` を参照） |

### A-2. BGM・アンビエント・環境音 — `src/engine/audio.js`

| 項目 | 内容 |
|---|---|
| 内容 | 雨・風・低周波ドローンの常時アンビエント（ノイズ合成＋フィルタ）、雷、囁き声、スタンガー（ジャンプスケア）、オルゴール（減衰正弦＋倍音）、ピアノ単音、心音、リバーブ（合成インパルス応答） |
| 理由 | Freesound.org / OpenGameArt.org が**接続できず**、実在する CC0 の和風ホラー BGM も検索で見つからなかったため |
| 作り方 | WebAudio API による**リアルタイム合成**（音源は持たず、コードで生成）。`fear` 値に応じてドローンのゲインとフィルタを連動させ、恐怖値で音楽が変化します |
| 品質についての正直な注記 | これは**「代替品（placeholder ではなく、れっきとした自作実装）」**ですが、**プロの BGM と同等の品質を保証するものではありません**。試聴もできていません（環境に音声出力・再生手段がないため）。外部 BGM を導入する場合は `audio.play(...)` の呼び出し箇所を `BGM` トラックの再生に差し替えてください |

### A-3. 足音以外の効果音のうち、ogg を wav に変換できなかったもの

Kenney パックには「雷」「囁き」「心音」「ガラス」に該当するクリップが含まれていなかったため、
これらは **A-2 と同じく WebAudio 合成**で自作しています（外部の代替候補そのものが存在しなかったため）。

## B. 演出上の理由で最初から自作したもの

### B-1. 手続き型プロップ — `src/game/custom.js`

`musicbox`（オルゴール）・`doll`（人形）・`key`（鍵）・`doll_altar`（祭壇）・`curtain`（カーテン）・`stair_up` / `stair_down`（階段）の 7 種。

- **理由**: これらは「物語上のキーアイテム」かつ「アニメーションさせたい対象」（オルゴールの蓋が開く、人形が首を動かす、鍵が光る、カーテンが揺れる）。外部の静止スプライトを貼るより、
  **フレーム単位で動かせる自作の手続き型描画**のほうが「演出をめちゃくちゃ凝る」という要件に合うため。
- 32px グリッドのピクセルアートとして、LPC の色数・明暗設計に合わせて描いています。

### B-2. ライティング / ポストエフェクト

2D レイキャスト可視性ポリゴン（`src/game/lighting.js`）と、WebGL のポストプロセス（グレイン・色収差・ビネット・ wobble・ブルーム・フェード、 `src/engine/postfx.js`）。

- **理由**: 「とにかく雰囲気を」という要件のコア。外部アセットでは表現できない動的処理であり、自作以外の選択肢がありません。

### B-3. 天候・粒子

雨・埃・霧・灰（`src/engine/fx.js` の `Particles`）。同じく動的処理のため自作。

### B-4. UI 一式 / レベルデータ / シナリオ

`index.html` + `src/style.css`（和文セリフ体のテキストボックス、レターボックス、章タイトル）、`src/game/rooms.js`（5 部屋のレイアウト・光源・ドア・調べポイント）、`src/game/script.js`（台詞・イベント・チェイス・結末）。いずれもこの作品のために書き起こしたものです。

## 差し替えポイント（外部アセットを後から入れる場合）

| 入れたいもの | 差し替え先 |
|---|---|
| 立ち絵 | `public/assets/portrait/{yui_base,yui_blink,yui_fear,yui_look}.png`（`src/ui/ui.js` の `PORTRAITS`） |
| BGM / 環境音 | `src/engine/audio.js` の `startAmbience()` / `setFear()` |
| 追加の効果音 | `public/assets/audio/` に置き `audio.play('<name>')`（`src/engine/audio.js` の `CLIPS`） |
| 追加のプロップ / タイル | `tools/extract.py` → `tools/build_atlas.py` で `atlas.png` / `atlas.json` に追加し、`src/game/rooms.js` の `props` から参照 |
