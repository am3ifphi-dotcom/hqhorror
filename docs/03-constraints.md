## 1. ネットワーク制約（この環境から接続できるホスト）

開発サンドボックスは外向き通信が **GitHub / npm レジストリ / PyPI 系ホストのみ** に制限されていました。

| ホスト | 状態 | 影響 |
|---|---|---|
| `github.com` / `codeload.github.com` / `api.github.com` | **可** | ここから全外部アセットを取得しました |
| `registry.npmjs.org` | **可** | フォントは npm 経由で取得 |
| `pypi.org` / `files.pythonhosted.org` | **可** | numpy / soundfile / fonttools を導入 |
| `opengameart.org` | **遮断** | 立ち絵・タイル追加・BGM の候補をすべて断念 |
| `freesound.org` | **遮断** | 環境音・BGM を断念 |
| `kenney.nl` | **遮断** | 本家ではなく GitHub ミラーを使用 |
| `fonts.googleapis.com` | **遮断** | Google Fonts の直リンクを断念（セルフホストに変更） |
| `cdn.jsdelivr.net` | **遮断** | CDN 経由の取得を断念 |
| `raw.githubusercontent.com` | **遮断** | 生ファイル直取得を断念（blobless clone で回避） |

## 2. 「検証できていない」こと（重要）

### 2-1. ブラウザでの目視・試聴は一切できていません

この環境には **ヘッドレスブラウザを含むブラウザが 1 つも存在しません**（Chromium / Chrome / Firefox / Playwright いずれも不在）。

そのため、以下は**すべて未検証**です。

- 実際にブラウザでゲームが**見た目どおりに表示される**こと
- 音が**意図したとおりに鳴る**こと（試聴手段がありません。波形は数値として生成しています）
- WebGL ポストエフェクト（グレイン・色収差・ビネット・wobble・ブルーム）が**実機で動く**こと
  - ヘッドレス描画では WebGL をスタブしているため、ポストエフェクトは**実行されていません**
  - ただし **WebGL が使えない／シェーダが失敗した場合は 2D フォールバック（単純転送＋フェード・フラッシュ・ビネット）に自動で切り替わる**実装になっており、その経路は上記のとおりヘッドレスで検証済みです
- UI レイアウト／日本語フォントの**実際の描画結果**（フォントは配信 200 確認のみ）

### 2-2. その代わりに実施した検証

| 検証 | 内容 | 結果 |
|---|---|---|
| 構文チェック | `node --check` を全 JS に対して実施 | エラーなし |
| ヘッドレス・スモークテスト | `npm run smoke`（jsdom + スタブ canvas/WebAudio、約 3,000 フレーム相当を模擬実行し、全 5 部屋・全 25 箇所の調べポイント・鍵の入手・施錠/解錠・チェイス・脱出・エンディング・タイトル復帰まで通す） | **全項目 PASS・ランタイムエラー 0**（`tools/smoke.mjs`） |
| 実描画キャプチャ | `REAL2D=1 node tools/shot.mjs`（@napi-rs/canvas で実ラスタライズし PNG を出力） | 10 枚のフレームを `tools/shots/` に出力。**WebGL ポストエフェクト抜きの 2D シーン**が描かれていることを数値で確認（部屋ごとの平均輝度 42–55 / 255） |
| アセット配信 | Vite 開発サーバーに対して HTTP 取得 | 主要アセット（atlas.png / atlas.json / 全 wav / 立ち絵 PNG / フォント woff2 / fonts.css）すべて **HTTP 200** |
| WebGL が使えない場合の代替描画 | `NOWEBGL=1 REAL2D=1 node tools/shot.mjs` 相当の実行 | WebGL を無効化しても**暗転せずに 2D フォールバックで描画される**ことを確認（`tools/shots/08_no_webgl.png`、平均輝度 55 / 255） |
| 参照整合性 | `node tools/verify_assets.mjs` | レベルデータが参照するフレーム 78 種すべてがアトラス（90 フレーム）または手続き型プロップとして解決。**欠落 0** |

## 3. 品質・一貫性に関する正直な注記

- **トーンの統一**: LPC のピクセルアート（32–64px）と生成した立ち絵（描き起こし）は**作風が異なります**。立ち絵側に desaturate ＋暗い色被りをかけることで画面内では馴染ませていますが、**完全に統一できているとは言えません**。
- **解像度**: ゲームは 480×270 の内部解像度で描画し、整数倍で拡大表示します（ピクセルアートのドットを崩さないため）。立ち絵と UI は DOM レイヤーなので拡大はスムーズです。
- **音量の統一**: 効果音はピーク正規化済み。アンビエント/ドローンは `setFear()` で恐怖値に応じてミックスを変化させていますが、**実際の聴感バランスは未調整（試聴不可のため）**です。
- **アトラス未使用フレーム**: アトラスの 90 フレーム中 19 フレームは現行のレベルデータからは参照されていません（将来の拡張用に同梱）。`node tools/verify_assets.mjs` で一覧できます。
